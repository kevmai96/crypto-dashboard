# Crypto Dashboard

A simple cryptocurrency data visualization dashboard built with vanilla JavaScript and Chart.js. This project allows users to compare the last 30 days of price data between two cryptocurrencies using live market data from the CoinGecko API.

# Features
- Compare two cryptocurrencies side-by-side
- Interactive line chart visualization
- Live crypto market data from CoinGecko API
- 30-day historical price tracking
- Responsive dashboard layout
- Built with plain HTML, CSS, and JavaScript

# Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)

- Bitcoin
- Ethereum
Solana
